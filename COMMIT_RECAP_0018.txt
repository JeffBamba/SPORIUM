📝 COMMIT MESSAGE SUGGERITO
===========================

Fix: Registrazione vasi nel calcolo pH dopo ottimizzazioni ServiceContainer

- Fix bug introdotto durante ottimizzazioni migrazione FindObjectOfType
  * Durante ottimizzazioni, PotActions cercava DayCycleController con FindObjectOfType in Awake()
  * Se DayCycleController non era ancora inizializzato, dayCycleController rimaneva null
  * Quando si piantava una pianta, RegisterPotIfNeeded() ritornava senza registrare il vaso
  * Le piante piantate non venivano incluse nel calcolo pH a fine giornata
  
- Soluzione: Tentativo di recupero DayCycleController se null
  * Aggiunto tentativo di recupero FindObjectOfType se dayCycleController è null in RegisterPotIfNeeded()
  * Risolve problema di timing durante inizializzazione dopo ottimizzazioni
  * Nessuna modifica al comportamento sistema pH (calcolo sempre a fine giornata)
  * Fix minimale che ripristina comportamento originale senza cambiare struttura

- Note sulle ottimizzazioni effettuate:
  * Migrazione FindObjectOfType → ServiceContainer (68% riduzione, 234→75 occorrenze)
  * Migrazione Resources.Load → AssetManager (centralizzazione con cache)
  * Implementazione SaveManager completo
  * Migrazione Singleton legacy → ServiceContainer
  * Durante queste ottimizzazioni, alcuni riferimenti FindObjectOfType rimasti hanno causato problemi di timing

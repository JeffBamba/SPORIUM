🐛 BUG FIXATI
=============

**BUG 1: Totale pH Non Corrispondeva ai Contributi Reali**
- **Numero:** BUG-0020-001
- **Descrizione:** Il totale "da contributi" sommava solo le voci individuali visibili, non i contributi cumulativi reali
- **Causa:** `GetCalculationBreakdown()` sommava `_plantContributions` che ha limite 50 e può non contenere tutti i contributi storici
- **Soluzione:** Modificato per usare `contrib.PlantsDrift`, `contrib.ActionsDrift`, `contrib.EventsDrift` (valori cumulativi reali)
- **Test:** Verificato con 2 piante per 6 giorni: totale corretto (12.0 invece di 4.0)
- **File:** `Assets/_Project/Scripts/Core/PhSystem.cs`

📚 LEZIONI APPRESE
==================

**Pattern Adottati:**
- Componente separato (`LedLightController`) per gestire effetti visivi Unity
- Ricerca automatica componenti/GameObject se non assegnati manualmente
- Toggle indipendente per ogni LED invece di ciclo unico
- Uso valori cumulativi per calcoli totali invece di sommare liste limitate

**Best Practices:**
- Separazione responsabilità: logica LED in `PotActions`, effetti visivi in `LedLightController`
- Debug console con font leggibili e layout adattivo
- Documentazione manuali Unity per setup scena
- Fix calcoli usando valori cumulativi invece di liste parziali

**Errori Evitati:**
- Non sommare liste limitate per calcoli totali (usare valori cumulativi)
- Non assumere che tutte le voci siano visibili in liste con limiti
- Verificare corrispondenza tra valori mostrati e valori reali

📚 LEZIONI APPRESE
==================

**Pattern Architetturali:**
- Creazione automatica UI runtime quando mancante migliora UX
- Late binding tramite eventi ServiceContainer per dipendenze circolari
- Controlli null sempre necessari in OnDestroy() e Update()
- Reflection utile per assegnazione campi privati in auto-setup

**Best Practices:**
- Sempre verificare null prima di accedere a riferimenti in metodi lifecycle
- Usare eventi per comunicazione tra sistemi invece di dipendenze dirette
- Creare metodi di fallback per creazione automatica componenti mancanti
- Log debug opzionali per tracciare flusso esecuzione

**Pattern Ricorrenti:**
- Singleton pattern per PlantDatabase (simile a ServiceContainer)
- ScriptableObject per dati configurabili (PlantData)
- Event-driven architecture per aggiornamenti UI (OnInventoryChanged)
- Auto-setup pattern per componenti UI runtime

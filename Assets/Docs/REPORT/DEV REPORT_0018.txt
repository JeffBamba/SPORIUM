🐛 BUG FIXATI
=============

**BUG 1: Piante piantate non rilevate nel calcolo pH (Post-Ottimizzazioni)**
- **Numero:** BUG-0018-001
- **Descrizione:** Dopo aver piantato due piante, nessuna delle due veniva rilevata nel calcolo del pH a fine giornata. Non apparivano nella HUD del pH calculation né nel conteggio del pH drift.
- **Contesto Ottimizzazioni:**
  Durante le ottimizzazioni principali del sistema (DEV REPORT #0014-#0017), sono state effettuate le seguenti migrazioni:
  - ✅ Migrazione FindObjectOfType → ServiceContainer (68% riduzione: 234→75 occorrenze)
  - ✅ Migrazione Resources.Load → AssetManager (centralizzazione con cache)
  - ✅ Implementazione SaveManager completo
  - ✅ Migrazione Singleton legacy → ServiceContainer
  - ✅ Wrapping Debug.Log con #if UNITY_EDITOR
  
  Durante queste ottimizzazioni, alcuni file hanno mantenuto riferimenti `FindObjectOfType` per componenti non ancora migrati completamente a ServiceContainer. Uno di questi era `PotActions.cs` che cercava `DayCycleController` con `FindObjectOfType` in `Awake()`.

- **Causa Root Cause:** 
  - Durante le ottimizzazioni, `PotActions.Awake()` cercava `DayCycleController` con `FindObjectOfType<DayCycleController>()`
  - Se `DayCycleController` non era ancora inizializzato o non presente nella scena durante `Awake()`, `dayCycleController` rimaneva null
  - Quando si piantava una pianta, `RegisterPotIfNeeded()` controllava se `dayCycleController == null` e ritornava immediatamente senza registrare il vaso
  - Di conseguenza, il vaso non veniva incluso nella lista `_registeredPots` del `DayCycleController`
  - A fine giornata, `CalculateAndRegisterPhDrift()` iterava solo sui vasi registrati, quindi le piante appena piantate non venivano considerate nel calcolo del pH
  
- **Soluzione:** 
  - Aggiunto tentativo di recupero `DayCycleController` se null in `RegisterPotIfNeeded()`
  - Se `dayCycleController` è null, viene cercato di nuovo con `FindObjectOfType` prima di registrare il vaso
  - Questo risolve il problema di timing durante inizializzazione dopo le ottimizzazioni
  - Aggiunti log di debug per verificare che la registrazione avvenga correttamente
  - Nessuna modifica al comportamento del sistema pH (calcolo sempre a fine giornata come prima)
  - Fix minimale che ripristina comportamento originale senza modificare struttura del sistema
  
- **Test:** ✅ Le piante piantate ora vengono correttamente rilevate nel calcolo del pH a fine giornata

**BUG 1: Label Condizione non si aggiorna nel Testo (rimane sempre SANA)**
- **Numero:** BUG-0021-001
- **Descrizione:** Il label "Condizione" nell'UI non si aggiorna correttamente, rimanendo sempre "Sana" anche quando la condizione cambia
- **Causa Identificata:**
  - In `PotHUDWidget.cs` linea 1442-1457: quando `plantData == null || _phSystem == null || _potSystemConfig == null`, viene usato il fallback con `state.ConditionLabel` che potrebbe non essere aggiornato
  - Il metodo `UpdateConditionUI()` potrebbe non essere chiamato quando la condizione cambia
  - Possibile desincronizzazione tra calcolo condizione (a fine giornata) e aggiornamento UI (on-demand)
- **Soluzione Proposta:**
  1. Verificare che `UpdateConditionUI()` venga chiamato ogni volta che si aggiorna la UI del vaso
  2. Assicurarsi che il calcolo condizione venga eseguito anche quando si apre il widget (non solo a fine giornata)
  3. Rimuovere il fallback statico e forzare sempre il ricalcolo quando possibile
  4. Aggiungere log di debug per tracciare quando viene aggiornato il label
- **Test Verifica:**
  - Cambiare pH Dome per forzare cambio condizione
  - Verificare che il label si aggiorni immediatamente
  - Verificare che il label mostri la condizione corretta dopo End Day

📚 LEZIONI APPRESE
==================

**Errori Ricorrenti:**
- Desincronizzazione tra calcolo stato (a fine giornata) e aggiornamento UI (on-demand)
- Fallback statici possono mascherare problemi di aggiornamento
- Tooltip troppo dettagliati possono confondere invece di aiutare

**Best Practices:**
- Sempre ricalcolare stato quando si apre UI invece di affidarsi a valori cached
- Separare informazioni essenziali da dettagli tecnici nei tooltip
- Usare linguaggio user-friendly invece di termini tecnici nell'UI
- Log di debug per tracciare aggiornamenti UI

**Pattern Adottati:**
- Sistema deterministico basato su timestamp invece di flag volatili
- Calcolo condizione centralizzato in PlantConditionSystem
- Tooltip modulari con sezioni separabili
- Tracking stato con decadimento graduale (giorni consecutivi LED)

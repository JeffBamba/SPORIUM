2.2 FLUSSO DI CRESCITA ATTUALE - COMPLETO
-----------------------------------------

1. PLANTING (Piantare) - COMPLETO
   └─> Player clicca "Plant" → UISeedSelector si apre
       └─> Player seleziona seme specifico → PotActions.DoPlant(seedTypeId)
           ├─> Lookup PlantData dal PlantDatabase usando seedTypeId
           ├─> Consuma seme dall'inventario
           ├─> Crea PotStateModel con Stage = Seed (1)
           ├─> Assegna PlantCode al PotStateModel (es. "PLT-STD-001")
           ├─> Imposta timestamp PlantedDay = CurrentDay
           ├─> Registra vaso in DayCycleController
           └─> Notifica PotGrowthController.OnPlanted()

2. DAILY GROWTH (Crescita Giornaliera) - SISTEMA AVANZATO
   └─> DayCycleController.HandleDayChanged(day)
       ├─> ResolveGrowthForAllPots(day)
       │   └─> Per ogni vaso con pianta:
       │       ├─> Calcola idratazione percentuale (0-100%)
       │       ├─> Verifica timestamp LastWateredDay e LastLitDay
       │       ├─> Incrementa DaysInCurrentStage
       │       ├─> GESTIONE HARVESTREADY: produzione frutti incrementale
       │       │   ├─> DaysInHarvestReady++ (contatore giorni in HarvestReady)
       │       │   ├─> Produzione: +1 frutto/giorno fino a max 3
       │       │   └─> Decay: dopo 3 giorni non raccolti → frutti = 0
       │       ├─> Ottieni StageRequirements da PlantData
       │       ├─> Verifica requisiti: idratazione range + LED richiesto + durata giorni
       │       ├─> Se requisiti soddisfatti → avanzamento automatico allo stadio successivo
       │       └─> Eventi e notifiche per cambio stadio + visuali
       └─> CalculateAndRegisterPhDrift() - INTEGRAZIONE pH COMPLETA
           ├─> Per ogni vaso con pianta valida:
           │   ├─> Ottiene PlantData.GetDailyPhDrift()
           │   ├─> Registra drift individuale con PhSystem.RegisterPlantDrift()
           │   └─> Logging dettagliato per debug
           └─> Cleanup contributi piante rimosse

3. ACTIONS (Azioni Player) - COMPLETE
   ├─> PotActions.DoWater()
   │   ├─> Consuma acqua dall'inventario
   │   ├─> Aumenta Hydration (max configurabile)
   │   ├─> OVERWATERING: se Hydration > max-1 → pH -5 (PhSystem)
   │   └─> Imposta LastWateredDay = CurrentDay
   │
   ├─> PotActions.DoLight(LedType)
   │   ├─> Consuma risorse (azioni/CRY)
   │   ├─> Aumenta LightExposure (max configurabile)
   │   ├─> LED EFFECTS: Blue +5 pH, Red -5 pH (PhSystem)
   │   └─> Imposta LastLitDay + LastLedType = CurrentDay + LedType
   │
   └─> PotActions.DoUproot()
       ├─> Rimuovi contributi pH della pianta
       ├─> Reset completo PotStateModel
       └─> Aggiungi WholePlant all'inventario

4. DECAY (Decadimento Fine Giorno)
   └─> DayCycleController.ApplyDecayAndCleanup(day)
       ├─> Hydration -= dailyHydrationDecay
       ├─> LightExposure = 0 (reset giornaliero)
       └─> Nessun reset timestamp (BLK-01.03A fix)

5. SISTEMA PRODUZIONE FRUTTI - COMPLETO
================================================================================

ATTUALE (Sistema Incrementale Avanzato):
---------------------------------------
- **HarvestReady Stage**: Produzione frutti automatica
- **Logica Incrementale**:
  * Giorno 1 ingresso HarvestReady: 1 frutto disponibile
  * Ogni giorno successivo (se non raccolto): +1 frutto fino a max 3
  * Dopo 3 giorni non raccolti: tutti i frutti decadono (AmountFruits = 0)
- **Tracking Avanzato**:
  * DaysInHarvestReady: giorni consecutivi in HarvestReady
  * DaysFruitsUnharvested: giorni senza raccolta (per decay)
  * AmountFruits: quantità attuale (float, supporta decimali)
- **Decay Automatico**: Previene accumulo infinito di frutti non raccolti

ESEMPIO Progressione Frutti:
```
Day 1: Entrata HarvestReady → AmountFruits = 1
Day 2: Non raccolto → AmountFruits = 2
Day 3: Non raccolto → AmountFruits = 3
Day 4: Non raccolto → AmountFruits = 0 (decay!)
```

GDD RICHIESTO vs ATTUALE:
-------------------------
✅ Produzione incrementale implementata
✅ Max 3 frutti implementato
✅ Decay dopo 3 giorni implementato
✅ Sistema raccolta pronto per implementazione

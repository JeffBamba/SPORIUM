2.2 FLUSSO DI CRESCITA ATTUALE
-------------------------------

1. PLANTING (Piantare) - AGGIORNATO BLK-02.02
   └─> Player clicca "Plant" → UISeedSelector si apre
       └─> Player seleziona seme → PotActions.DoPlant(seedTypeId)
           ├─> Cerca PlantData dal PlantDatabase usando seedTypeId
           ├─> Consuma seme dall'inventario
           ├─> Crea PotStateModel con Stage = Seed (1)
           ├─> Assegna PlantCode al PotStateModel
           ├─> Imposta timestamp PlantedDay = CurrentDay
           ├─> Registra vaso in DayCycleController
           └─> Notifica PotGrowthController.OnPlanted()

2. DAILY GROWTH (Crescita Giornaliera) - AGGIORNATO BLK-02.02
   └─> DayCycleController.HandleDayChanged(day)
       ├─> ResolveGrowthForAllPots(day)
       │   └─> Per ogni vaso con pianta:
       │       ├─> Verifica timestamp LastWateredDay e LastLitDay
       │       ├─> Calcola punti crescita:
       │       │   ├─> Cura ideale (acqua + luce) = +2 punti
       │       │   ├─> Cura parziale (una delle due) = +1 punto
       │       │   └─> Nessuna cura = +0 punti
       │       ├─> Aggiorna GrowthPoints
       │       ├─> Controlla avanzamento stadi:
       │       │   ├─> Seed → Sprout: se GrowthPoints >= 2
       │       │   └─> Sprout → Mature: se GrowthPoints >= 3
       │       └─> Notifica cambio stadio (eventi + visuali)
       └─> CalculateAndApplyPhDrift() - NUOVO BLK-02.02
           ├─> Per ogni vaso con pianta:
           │   ├─> Ottiene PlantData da PotStateModel.GetPlantData()
           │   └─> Somma DailyPhDrift alla somma totale
           └─> Registra drift totale in PhSystem.RegisterPlantDrift()

3. ACTIONS (Azioni Player)
   ├─> PotActions.DoWater()
   │   ├─> Consuma acqua dall'inventario
   │   ├─> Aumenta Hydration (max 3)
   │   └─> Imposta LastWateredDay = CurrentDay
   │
   └─> PotActions.DoLight()
       ├─> Consuma risorse (azioni/CRY)
       ├─> Aumenta LightExposure (max 3)
       └─> Imposta LastLitDay = CurrentDay

4. DECAY (Decadimento Fine Giorno)
   └─> DayCycleController.ApplyDecayAndCleanup(day)
       ├─> Hydration -= dailyHydrationDecay (default: -1)
       └─> LightExposure = 0 (reset giornaliero)

4. SISTEMA PUNTI CRESCITA
================================================================================

ATTUALE:
--------
- GrowthPoints: accumulo punti per avanzamento stadi
- Calcolo giornaliero basato su cura ricevuta:
  * Cura ideale (acqua + luce) = +2 punti
  * Cura parziale (una delle due) = +1 punto
  * Nessuna cura = +0 punti
- Soglie configurabili:
  * Seed → Sprout: 2 punti (PlantGrowthConfig.pointsSeedToSprout)
  * Sprout → Mature: 3 punti (PlantGrowthConfig.pointsSproutToMature)

GDD RICHIESTO:
--------------
- Sistema più complesso con requisiti per stadio:
  * Seed → Sprout: richiede acqua/luce/pH nella banda corretta
  * Sprout → Growth: richiede idratazione 40-60%, Blue LED moderato
  * Growth → Flowering: richiede parametri soddisfatti per 2 giorni consecutivi
  * Flowering → HarvestReady: richiede Red LED (accelera), rischio Burn Stress
  * HarvestReady: produzione frutti (1 frutto iniziale, +1/giorno fino a 3 max)
  * Resting: nessuna crescita/produzione dopo Harvest

DIFFERENZE:
-----------
- ⚠️ Sistema attuale troppo semplificato
- ❌ Non considera pH per avanzamento stadi
- ❌ Non considera requisiti specifici per stadio (idratazione range, LED tipo)
- ❌ Non gestisce produzione frutti incrementale
- ❌ Non gestisce ciclo Resting

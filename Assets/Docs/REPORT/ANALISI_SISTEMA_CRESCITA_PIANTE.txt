2.2 FLUSSO DI CRESCITA ATTUALE
-------------------------------

1. PLANTING (Piantare)
   └─> PotActions.DoPlant()
       ├─> Consuma seme dall'inventario
       ├─> Crea PotStateModel con Stage = Seed (1)
       ├─> Imposta timestamp PlantedDay = CurrentDay
       ├─> Registra vaso in DayCycleController
       └─> Notifica PotGrowthController.OnPlanted()

2. DAILY GROWTH (Crescita Giornaliera)
   └─> DayCycleController.HandleDayChanged(day)
       └─> ResolveGrowthForAllPots(day)
           └─> Per ogni vaso con pianta:
               ├─> Verifica timestamp LastWateredDay e LastLitDay
               ├─> Calcola punti crescita:
               │   ├─> Cura ideale (acqua + luce) = +2 punti
               │   ├─> Cura parziale (una delle due) = +1 punto
               │   └─> Nessuna cura = +0 punti
               ├─> Aggiorna GrowthPoints
               ├─> Controlla avanzamento stadi:
               │   ├─> Seed → Sprout: se GrowthPoints >= 2
               │   └─> Sprout → Mature: se GrowthPoints >= 3
               └─> Notifica cambio stadio (eventi + visuali)

3. ACTIONS (Azioni Player)
   ├─> PotActions.DoWater()
   │   ├─> Consuma acqua dall'inventario
   │   ├─> Aumenta Hydration (max 3)
   │   └─> Imposta LastWateredDay = CurrentDay
   │
   └─> PotActions.DoLight()
       ├─> Consuma risorse (azioni/CRY)
       ├─> Aumenta LightExposure (max 3)
       └─> Imposta LastLitDay = CurrentDay

4. DECAY (Decadimento Fine Giorno)
   └─> DayCycleController.ApplyDecayAndCleanup(day)
       ├─> Hydration -= dailyHydrationDecay (default: -1)
       └─> LightExposure = 0 (reset giornaliero)

📚 LEZIONI APPRESE
==================

**Errori Ricorrenti Identificati:**
1. **UI Elements Non Trovati**: Pattern comune dove FindTextInChildren non trova elementi opzionali
   - **Soluzione**: Gestire campi opzionali senza warning eccessivi, creare dinamicamente se necessario
2. **EventTrigger su Oggetti Disattivati**: Pattern comune che causa tooltip non funzionanti
   - **Soluzione**: EventTrigger deve essere su oggetti attivi, spostare se necessario
3. **Discrepanza Valori UI vs Calcoli**: Pattern comune dove UI mostra valori diversi da calcoli
   - **Soluzione**: Usare stesso calcolo in UI e tooltip, evitare duplicazione logica
4. **Dialog Non Visibili**: Pattern comune dove dialog istanziati ma non resi visibili
   - **Soluzione**: Verificare Canvas parent, SetActive corretto, istanziazione in root Canvas

**Best Practices Adottate:**
1. **Configurazioni Separate**: Ogni sistema ha ScriptableObject config per facilità modifica
2. **Logging Debug**: Logging estensivo per tracciare problemi runtime
3. **UI Manuale vs Runtime**: Preferire UI manuale in Unity per controllo completo
4. **Colori Dinamici**: Colori basati su valori reali invece di stati azioni
5. **Feedback Utente**: Toast notifications per tutte le azioni importanti
6. **Range Display**: Mostrare sempre range ideale per parametri critici

**Pattern Adottati:**
- **RNG Pattern**: Calcolo probabilità con reroll opzionale per spray
- **State Tracking Pattern**: Tracking giorni consecutivi per calcolo rischio
- **Progressive Penalty Pattern**: Penalità crescenti per livelli rischio maggiori
- **Conditional Bonus Pattern**: Bonus applicati solo in condizioni specifiche (es. Growth stage)

🐛 BUG FIXATI
=============

BUG-0036-001 — UI Toolkit “Broken text PPtr … GUID 0000… invalid”
- **Causa:** UXML conteneva `<Style src="project://database/... guid=0000...">` placeholder non valido.
- **Soluzione:** Uso di riferimenti relativi ai `.uss`:
  - `PotActionsMenu.uxml` → `<Style src="PotActionsMenu.uss" />`
  - `SeedInventoryMenu.uxml` → `<Style src="SeedInventoryMenu.uss" />`
  - `IrrigationDialog.uxml` → `<Style src="IrrigationDialog.uss" />`
- **Verifica:** Reimport UXML senza errori importer.

BUG-0036-002 — CS0127: return con void in SeedInventoryMenu.AddEmptyRow
- **Causa:** Metodo `AddEmptyRow` era `void` ma restituiva un `VisualElement`.
- **Soluzione:** `AddEmptyRow` aggiunge la riga direttamente alla `_list`.
- **Verifica:** Compilazione C# ok.

BUG-0036-003 — INSPECT non apriva PlantCardV2
- **Causa:** `PotActionsMenu.OnInspectClicked()` chiamava `Hide()` prima di `OpenForInspect()`, azzerando `_currentPot`.
- **Soluzione:** Salvato `PotSlot` in variabile locale prima di `Hide()`.
- **Verifica:** INSPECT apre PlantCardV2 correttamente.

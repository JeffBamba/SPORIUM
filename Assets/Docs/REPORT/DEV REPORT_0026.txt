🐛 BUG FIXATI
=============

**BUG 1: NullReferenceException in ElevatorSystem.TeleportPlayer**
- **Numero:** BUG-FIX-ELEVATOR-001
- **Descrizione:** NullReferenceException alla riga 235 quando si accedeva a player.position dopo yield return
- **Causa:** Durante l'attesa della coroutine (WaitForSeconds), player, levels[levelIndex] o elevatorSection potevano diventare null o essere distrutti
- **Soluzione:** Aggiunti null checks dopo yield return e all'interno del loop, con early exit se oggetti sono null
- **Test Verificazione:** 
  - Test teleport con player che esce dall'ascensore durante il delay
  - Test teleport con distruzione GameObject durante coroutine
  - Verificato che non si verifica più NullReferenceException

📚 LEZIONI APPRESE
==================

**Pattern Implementativi:**
- Usare distanza normalizzata per calcolare malus proporzionale (Lerp tra min e max)
- Aggiornare countdown ogni giorno in ResolveGrowthForPot() per tracking continuo
- Evitare spam notifiche mostrando solo quando countdown cambia
- Modificare logica incrementale esistente senza rompere decay system
- Mantenere retrocompatibilità con sistema esistente

**Best Practices:**
- Null checks dopo yield return in coroutine (oggetti possono essere distrutti durante attesa)
- Early exit con yield break se oggetti diventano null durante esecuzione coroutine
- Separare malus estremo da malus standard per maggiore granularità
- Usare ServiceContainer per accesso a sistemi invece di FindObjectOfType

**Errori Ricorrenti:**
- NullReferenceException in coroutine quando oggetti vengono distrutti durante yield
- Dimenticare di aggiornare altezza contenuto scroll view quando si aggiungono nuove sezioni
- Non resettare countdown quando condizioni cambiano (pH non più estremo)

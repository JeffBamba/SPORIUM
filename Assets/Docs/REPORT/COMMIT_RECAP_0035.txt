# 📝 **COMMIT RECAP 0035 - POT OPS + SEED INVENTORY + IRRIGATION (UI TOOLKIT)**

## 🎯 **PANORAMICA**
Implementato il nuovo flusso di interazione POT basato su UI Toolkit:
- Click POT → **POT OPS** menu (EMPTY/OCCUPIED)
- **PLANT** → **SEED INVENTORY** (UI Toolkit, border giallo) → selezione seed
- → **IRRIGATION PROTOCOL** (UI Toolkit, border blu) → SÌ/NO

- POT occupato: **INSPECT / HARVEST / REMOVE** (ordine richiesto) con chiusura menu solo su successo per HARVEST/REMOVE
- PlantCardV2: non si pianta più dalla card (PLANT hidden/disabled a runtime); apertura solo via INSPECT

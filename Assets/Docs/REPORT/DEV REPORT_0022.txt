🏗️ ARCHITETTURA IMPLEMENTATA
==============================

**TRANCE 1 - Flusso Applicazione Fertilizzante:**
```
Player clicca "Fertilizzare"
    ↓
UIFertilizerSelector.Show() → mostra inventario fertilizzanti
    ↓
Player seleziona fertilizzante
    ↓
PotActions.DoFertilize(fertilizerItemId)
    ↓
Verifica inventario → rimuove item
    ↓
FertilizerSystem.IsCompatible() → verifica compatibilità genetica
    ↓
Se incompatibile → PotEvents.EmitPlantDied() → pianta muore
Se compatibile → FertilizerSystem.ApplyFertilizer() → aumenta FertilizerLevel
    ↓
Se Resting → transizione automatica a Flowering
    ↓
PotEvents.EmitPotAction(Fertilize) → aggiorna UI
```

**TRANCE 1 - Flusso Decadimento Fertilizzante:**
```
DayCycleController.OnDayChanged()
    ↓
ResolveGrowthForPot() per ogni vaso
    ↓
FertilizerSystem.DecayFertilizer(pot) → -5% FertilizerLevel
    ↓
Se FertilizerLevel > 0 → incrementa DaysFertilizerActive
Se FertilizerLevel = 0 → reset DaysFertilizerActive
```

**TRANCE 2 - Flusso Calcolo Punti Giornalieri:**
```
DayCycleController.OnDayChanged()
    ↓
ResolveGrowthForPot() per ogni vaso
    ↓
GrowthPointsCalculator.CalculateDailyPoints(pot, plantData, config)
    ↓
Verifica idratazione nel range → +1 GrowthPointsWater
Verifica luce (LED + intensità) nel range → +1 GrowthPointsLight
Verifica fertilizzante nel range → +1 GrowthPointsFertilizer
    ↓
Se TotalPoints >= 3 → incrementa DaysConsecutiveOptimal
Se TotalPoints < 3 → reset DaysConsecutiveOptimal
```

**TRANCE 2 - Flusso Avanzamento Stadio:**
```
ResolveGrowthForPot() verifica requisiti avanzamento:
    ↓
pointsOk: punti accumulati >= punti richiesti
durationOk: giorni nello stadio >= giorni richiesti (con modificatore condizione)
optimalDaysOk: giorni consecutivi ottimali >= giorni richiesti
hydrationOk: idratazione nel range ideale
ledOk: LED corretto per lo stadio
fertilizerOk: fertilizzante nel range (opzionale per Seed)
!BlocksAdvancement: condizione non blocca
    ↓
Se tutti i requisiti OK → avanza al prossimo stadio
    ↓
Reset punti crescita: GrowthPointsWater/Light/Fertilizer = 0
Reset giorni ottimali: DaysConsecutiveOptimal = 0
```

- Seed: 40-75-100%
- Sprout: 40-60-80%
- Growth: 40-60-80%
- Flowering: 20-40-60%
- HarvestReady: non richiesto
- Resting: 30-50-70%

**Range Luce (identici per tutte le famiglie):**
- Seed: 50-75-100%
- Sprout: 50-75-100%
- Growth: 50-75-100%
- Flowering: 50-75-100%
- HarvestReady: non richiesto
- Resting: 30-50-70%

**Compatibilità Fertilizzanti:**
- Standard: solo Standard (Pure/Prohibited → morte immediata)
- Pure: Pure o Standard (Prohibited → morte immediata)
- Evil: Prohibited o Standard (Pure → morte immediata)

**Modificatori Condizione:**
- Rigogliosa: -1 giorno (crescita più veloce)
- Sana: 0 giorni (normale)
- Stressata: +1 giorno (crescita più lenta)
- Appassita: +2 giorni (crescita molto lenta)
- Critica: +3 giorni (crescita estremamente lenta) + blocca avanzamento

**Logica Speciale Seed Stage:**
- Fertilizzante opzionale (OK se 0% o in range)
- Richiede 2 punti (Water + Light) invece di 3
- Giorno ottimale se TotalPoints >= 2
- Giorni consecutivi ottimali richiesti: >= 1

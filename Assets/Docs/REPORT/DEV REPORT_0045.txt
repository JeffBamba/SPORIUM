🐛 BUG FIXATI
=============
- **AUTO-QUEUE-ERR-001 (azioni non partono con queue multiple)**:
  - **Causa:** automazione seriale unica bloccava pot diversi.
  - **Fix:** queue per pot e run parallelo con preservazione ordine per pot.
  - **Verifica:** ✅ queue multi-pot avvia braccia in parallelo.

- **PCV3-QUEUE-AP-002 (silent fail con AP/Item insufficienti)**:
  - **Causa:** errore mostrato solo nel terminale chiuso, nessun feedback esterno.
  - **Fix:** toast error per AP o item insufficienti.
  - **Verifica:** ✅ toast visibile anche con terminale chiuso.

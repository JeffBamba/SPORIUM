7.1 FIX MAXHYDRATION
--------------------
✅ RISOLTO (2025-01-XX)
- Problema: Annaffiare produceva 33% invece di 25%
- Causa: MaxHydration era 3 invece di 4
- Soluzione: Cambiato MaxHydration da 3 a 4 in tutti i file
- File modificati:
  - PotSystemConfig.cs (valore default e CreateDefaultConfig)
  - PotActions.cs (fallback GetMaxHydration)
  - Pot System Config.asset (configurazione)
  - PotSystemConfig_Default.asset (configurazione)
  - DayCycleController.cs (fallback e warning)
  - PotHUDWidget.cs (fallback calcolo percentuale)
  - PotDetailsWidget.cs (fallback calcolo percentuale)
- Risultato: Ogni annaffiatura ora produce esattamente 25% (1/4) ✅

7.2 FIX DONTDESTROYONLOAD
--------------------------
✅ RISOLTO (2025-01-XX)
- Problema: "DontDestroyOnLoad only works for root GameObjects"
- Causa: SaveManager, AssetManager, EventSystem, PlantDatabase erano figli nella gerarchia
- Soluzione: Aggiunto controllo per spostare GameObject alla root prima di DontDestroyOnLoad
- File modificati:
  - SaveManager.cs
  - AssetManager.cs
  - EventSystem.cs
  - PlantDatabase.cs
- Risultato: Nessun errore DontDestroyOnLoad ✅

7.3 FIX SERVICECONTAINER
------------------------
✅ RISOLTO (2025-01-XX)
- Problema: Warning "Servizio già registrato" e "Servizio non trovato"
- Causa: Doppia registrazione e ricerca servizi prima della registrazione
- Soluzione:
  - ServiceContainer.Register ora ignora se stessa istanza già registrata
  - Aggiunto parametro suppressWarning a Get() per evitare warning durante inizializzazione
  - GamePlayInstaller verifica se servizio già registrato prima di registrarlo
  - GameManager verifica se già registrato prima di registrarsi
- File modificati:
  - ServiceContainer.cs
  - GamePlayInstaller.cs
  - GameManager.cs
  - AssetManager.cs
  - SaveManager.cs
  - PlantDatabase.cs
- Risultato: Nessun warning ServiceContainer ✅

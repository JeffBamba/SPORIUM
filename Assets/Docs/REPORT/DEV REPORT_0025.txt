📚 LEZIONI APPRESE
==================

**Pattern Adottati:**
- Lazy initialization per sistemi non sempre disponibili (ServiceContainer, configs)
- Cache references per evitare FindObjectOfType ripetuti
- Coordinate relative in scroll view (offset invece di consoleX + offset)
- Calcolo altezza dinamica per scroll view (spazio disponibile - margini)

**Best Practices:**
- Tutte le modifiche debug protette da `#if UNITY_EDITOR || DEVELOPMENT_BUILD`
- Logging debug per tutte le modifiche (AddLog)
- Inizializzazione valori input quando si seleziona POT
- Retry buttons per sistemi non disponibili al momento

**Problemi Risolti:**
- Sezioni tagliate risolte con scrolling verticale dedicato
- Accesso sistemi migliorato con lazy initialization e cache
- Coordinate GUI convertite correttamente per scroll view

🔧 DETTAGLI TECNICI
===================

**Sistema SporiumLogger:**
- Namespace: Sporae.DevTools
- Classe: SporiumLogger (static)
- Metodi principali:
  - Log(LogLevel, LogCategory, string, object)
  - LogDebug/LogInfo/LogWarning/LogError/LogCritical(LogCategory, string, object)
  - SetCategoryEnabled(LogCategory, bool)
  - SetMinLogLevel(LogLevel)
  - ExportLogsToFile(string, bool)
  - ExportLogsToCSV(string)
  - GetHistory() / ClearHistory()

**GlobalStateInspector:**
- Toggle: KeyCode.F1
- Sezioni implementate:
  - GameManager State (CRY, Actions, Day)
  - pH System State (Current pH, Band, Contributi)
  - Pot System State (Lista pot con stato dettagliato)
  - Inventory State (Items, Quantità)
  - Day Cycle State (Current Day, Time Scale)
  - Save System State (Salvataggi disponibili)
  - Performance Metrics (FPS, Memory, GC Alloc)

**Categorie Utilizzate:**
- LogCategory.UI: Tutti i log UI (PotDetailsWidget, HUDController, ecc.)
- LogCategory.Core: Sistemi core (GameManager, ServiceContainer, AppRoot, ecc.)
- LogCategory.Dome: Sistema Dome (DayCycleController, MoldSystem, ecc.)
- LogCategory.Pot: Sistema Pot (PotActions, PotEvents, PotGrowthController, ecc.)
- LogCategory.Ph: Sistema pH (PhSystem, PhSystemIdleOscillation)
- LogCategory.Inventory: Sistema inventario (Inventory, ItemFabric, DragDropUI)
- LogCategory.Save: Sistema salvataggio (SaveManager)
- LogCategory.Audio: Sistema audio (AudioListenerManager)
- LogCategory.DevTools: Strumenti debug (console debug, GrowthDebugger, ecc.)
